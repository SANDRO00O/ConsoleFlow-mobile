# Security Policy

## Supported Versions

Only the latest release of ConsoleFlow — available on [F-Droid](https://f-droid.org/packages/space.karrarnazim.ConsoleFlow/) and the [Releases page](https://github.com/ConsoleFlow-Group/ConsoleFlow-mobile/releases) — is supported with security fixes.

## Reporting a Vulnerability

If you find a security issue — anything from a WebView/JS-bridge escape to an unsafe network request — please **do not** open a public issue.

Instead, use GitHub's private reporting:

1. Go to the [Security tab](https://github.com/ConsoleFlow-Group/ConsoleFlow-mobile/security) of this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

We'll do our best to acknowledge reports quickly and keep you updated as we work on a fix. Please give us reasonable time to release a patch before any public disclosure.
