New: Search Suggestions — typing in the address bar or home page now shows live search suggestions, like Chrome.

- Full-screen search overlay with suggestions that update as you type
- Each suggestion has a fill button (↗) to autofill the bar without navigating
- Supports Google, DuckDuckGo, Bing, and Brave
- Can be disabled in Settings

Android TV / API 22:
- The app now installs on Android 5.1.1 devices (minSdk lowered from 24 to 22)
- Search overlay is fully navigable with D-pad and TV remotes
- Fixed a crash in the download manager on API 22
