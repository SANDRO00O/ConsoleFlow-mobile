# Changelog

## v2.2.11

### What is new

- Fixed the status bar overlapping the browser content on the home page.
- Fixed search and downloads sometimes firing twice from a single Enter/Go press.
- Fixed the app appearing to launch/restart twice on cold start.
- Added a new in-app **Logs** screen (Settings → View Logs) with session activity, crash capture, and share/clear actions — helpful when filing bug reports.
- Fixed the status bar overlapping content on the About, Settings, and Downloads screens.
- Fixed the address bar getting clipped at the top and bottom on devices with a taller status bar (e.g. Android 16).
- Updated the developer link to karrarnazim.pages.dev.
