# Code of Conduct

## Our Pledge

We want ConsoleFlow to be a welcoming project for anyone who wants to use it, report a bug, or contribute code — regardless of experience level, background, or which platform they're debugging on. As contributors and maintainers, we pledge to make participation in this project a harassment-free experience for everyone.

## Expected Behavior

- Be respectful of differing viewpoints and experiences — not everyone approaches a problem the same way.
- Give and accept constructive feedback gracefully; code review comments are about the code, not the person.
- Assume good faith. Most misunderstandings in a text-based medium are just that — misunderstandings.
- Be patient with new contributors, including people whose first language isn't English or who are new to Android/Kotlin.

## Unacceptable Behavior

- Harassment, insults, or derogatory comments, in public or private.
- Personal or political attacks unrelated to the project.
- Publishing others' private information without their explicit permission.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This Code of Conduct applies within all project spaces — issues, pull requests, discussions, commit messages — and in any other setting where someone is representing the project or its community.

## Enforcement

Instances of unacceptable behavior can be reported by opening a private security advisory in this repository (see [SECURITY.md](SECURITY.md)) or by contacting a maintainer directly. All reports will be reviewed and investigated, and will result in a response deemed necessary and appropriate to the circumstances.

---

*This Code of Conduct is adapted in spirit from common open-source community standards such as the [Contributor Covenant](https://www.contributor-covenant.org/).*
